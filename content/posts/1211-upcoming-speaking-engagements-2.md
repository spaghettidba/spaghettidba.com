In the next few months I will be speaking at some awesome events around Europe.

&nbsp;

<a href="http://www.sqlbits.com/"><span style="text-decoration:underline;"><strong>SQLBits - April 5-8 </strong></span></a>

<a href="http://www.sqlbits.com/"><img class="alignnone  wp-image-1236" src="/wp-content/uploads/2017/02/sqlbitslogo.png" alt="sqlbitslogo" width="259" height="114" /></a>

SQLBits is THE SQL Server event in Europe, with a very long tradition and a fantastic audience. I totally love SQLBits!
This time I will speak about "<a href="http://www.sqlbits.com/Sessions/Event16/Benchmarking_like_a_PRO">Benchmarking like a PRO</a>". In this session I will demonstrate how to capture a baseline with RML Utilities and how to replay it against a target machine to compare baseline and benchmarks. I will use a PowerShell script of my creation and I will walk you through the code and outcomes.
