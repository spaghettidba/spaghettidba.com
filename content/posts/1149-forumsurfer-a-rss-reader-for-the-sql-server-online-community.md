Today I published the first release of <a href="https://github.com/spaghettidba/ForumSurfer">ForumSurfer</a>, a RSS reader designed explicitly to be a tool for the SQL Server online community.

Here is a screenshot:

<a href="/wp-content/uploads/2016/08/forumsurfer.png"><img class="alignnone size-full wp-image-1157" src="/wp-content/uploads/2016/08/forumsurfer.png" alt="ForumSurfer" width="604" height="327" /></a>

ForumSurfer has some unique features that will help you help others online:
<ul>
 	<li>it is designed to help you keep an eye on multiple communities through their RSS feeds</li>
 	<li>it opens questions in the integrated web browser</li>
 	<li>it can update from the feeds much more often than online RSS readers do</li>
 	<li>it has built-in support for boilerplate answers</li>
 	<li>it supports high-DPI displays, letting you choose the appropriate zoom level for individual sites</li>
 	<li>it can import/export OPML files (you can start by importing the <a href="https://gist.github.com/spaghettidba/4b5a6d47bb61a16456c5400f4bc1cd7a">OPML file</a> containing all the online SQL Server communities I'm keeping on the radar)</li>
</ul>
What are you waiting for? <a href="https://github.com/spaghettidba/ForumSurfer/releases/latest">Download now</a> the latest release of ForumSurfer and start being helpful!
