The day has come at last! SQL Server 2014 CTP1 is <a href="http://t.co/dJyeO4AW9g">available for download</a>!

You can now start playing with Hekaton and all the exciting features included in this version.

Mi suggestion is to create a new virtual machine for your playground: this CTP version won't install on a machine with other installations of SQL Server.

If you prefer it and you have a subscription, you can also try SQL Server 2014 on Windows Azure.

<img class="alignnone" alt="" src="https://pbs.twimg.com/media/BNlkHG6CYAAo4Hi.png:large" width="535" height="386" />

While you're at it, take the time to read the <a href="http://msdn.microsoft.com/en-us/library/bb418471(v=sql.10).aspx">documentation</a> carefully. You'll soon discover that the in-memory engine has <a href="http://msdn.microsoft.com/en-us/library/dn246937(v=sql.120).aspx">some limitations</a>. I hope that the next versions will overcome them and give us a more usable software.

What are you waiting for? <a href="http://technet.microsoft.com/en-US/evalcenter/dn205290.aspx">Download now</a>!
